# Curio · HTML presentation

请保留本目录中的全部文件，并用浏览器打开 `index.html`。

## 演讲者视图（推荐）

1. 在本目录运行 `python -m http.server 8765`，访问 `http://127.0.0.1:8765/`。
2. 点击 **Presenter · P** 或按 **P**，允许浏览器打开弹出窗口。原窗口变为纯观众画面，新窗口显示当前页、下一页、英文与中文讲稿、计时。
3. 在 Windows 显示设置中选择“扩展这些显示器”。将原窗口拖到投影仪并按 **F** 全屏，将演讲者窗口留在自己的屏幕。
4. 两个窗口均可用空格 / → 前进、← 后退；第 7 页首次前进显示结果，再次前进进入第 8 页。计时与结果揭示状态会同步。关闭演讲者窗口后，原窗口的控制栏会恢复。

若只需临时查看讲稿，可直接打开 `index.html`，按 **N**。全屏观众画面不显示讲稿。

- 第7页进入时显示问号，等待不会自动显示结果。点击 Reveal result 或按空格/右方向键/Next 揭示；再前进则进入第8页。返回第7页会恢复问号。Replay reveal 按钮重置，随后可再次揭示。
- 第8页图表仍自动入场，说明与结论重新布局。
- 原翻页、模块过场、计数和轮播机制保留。
- 第10页流程图为内联 SVG，保留原两排结构。
- 第3页实际前端需运行 F:/Curio/Start Curio.cmd；未启动时显示引导页。
- 第11页证据图内的小字属于原始图片，本次没有重绘该证据图。

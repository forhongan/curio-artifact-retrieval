## 解释边界

- 元数据银标与 BM25/slot 共享信息来源，因此高分不能证明更强的视觉理解。
- 器型/材料 probe 从馆藏弱标签训练，概率只用于软重排；年代、文化和身份不能从该分类器视为已识别。
- 当前没有真人标注，不报告真人一致性、双标 κ 或人工 gold 收益。
- 独立 AI 盲图审计、真实 API 延迟与浏览器验收在对应附录中单独报告。

# 五个研究与演讲模块

各模块是可以交给组员整理或继续研究的工作包，对应HTML演示的同名模块，不预设成员归属。

| 模块 | 工作包 | 演示页 | 讲述时间 |
|---|---|---|---|
| A | [数据与相关性评测](handoff/A_DATA.md) | 1–2 | 55秒 |
| B | [视觉表示、微调与双语查询](handoff/B_REPRESENTATION.md) | 3–4 | 80秒 |
| C | [全库yes/no集合边界](handoff/C_SET_BOUNDARY.md) | 5 | 50秒 |
| D | [专业名称、外部参考图与图图检索](handoff/D_REFERENCES.md) | 6–7 | 95秒 |
| E | [视觉辅助、性能与产品集成](handoff/E_COMPONENTS.md) | 8、10–11 | 110秒 |

讲述合计6分30秒；第9页操作展示60秒单独计时，总计7分30秒。讲者稿与演练流程见 [PRESENTATION_GUIDE.md](PRESENTATION_GUIDE.md)。

阅读顺序：本页 → 对应工作包 → 工作包内证据。当前开发状态见 [CURRENT_STATE.md](CURRENT_STATE.md)，技术稿见 [TECHNICAL_REPORT_DRAFT.md](TECHNICAL_REPORT_DRAFT.md)。

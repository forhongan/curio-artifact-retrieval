# 外部参考图与专门视觉方法：实现与实测

2026-10-30。此页记录新增研究路线，原 v2 冻结 test 结果仍在 `VISUAL_RESULTS.md`。所有数字来自本地实际运行；没有真人标注、年代识别准确率或全库 Recall 声称。

## 对应用户提出的四项工作

1. **实际类别扩展**：原图库 4,692 图保留。另下载 101 张官方 CC0 图像，保守分为 66 个作品/册页家族，实际对象类型为 book75/calligraphy17/painting6/textile3。已编码为可选择的 4,793 图扩展图库，界面文本搜索可切换；未进入旧训练或评测。新增数据明显偏向册页，这还不是全面的文物门类覆盖。
2. **专业文本→外部参考图片→图图匹配**：已实现。按文本中的已映射类别、器型、来源年代选择事先真实采集的馆外参考图，再使用这些图片的特征检索本地图库。在线使用缓存参考图库，不伪称每次请求都实时联网；规划器目前是双语规则，没有暗中调用 LLM。另有原始图片上传入口，两者是不同入口。
3. **可信性描述**：已修正旧版错误。展示实际余弦差、所覆盖约束、真实比较的信号一致性及未知项，不从 RRF 排名差或模型可用性推导正确率。参考图相互一致也不能证明结果正确。融合前诊断与最终排序明确区分。
4. **器型/颜色/纹理专门处理**：在全部 4,692 图上建立了前景遮罩、形状、颜色与纹理描述子；实际跑过单独检索和融合消融。另实现冻结 DINO patch 的局部对应与软轮廓重排，记录独立弱标签实验。没有把传统统计特征称作训练过的龙纹识别器。

## 实际运行的方法

- SigLIP：复用生产图像塔及 LoRA，比较参考图与图库图像，不读本地标题、年代或标签来排名。
- DINOv2-small：固定模型 revision `ed25f3a31f01632728cabb09d1542f84ab7b0056`，384 维 CLS 图像特征，已对全库建立索引。
- 多参考：单张、逐张 cosine 均值、最大值。归一化平均向量与逐张 cosine 均值的排名在数学上相同，只改变分数尺度，不算两种独立有效改进。
- 传统前景：稳健边框 RGB 平面背景估计、连通域、拒绝复杂背景/触边/大片内部缺失。形状132维、前景 HSV192维、LBP/梯度纹理34维；888/4692（18.9%）通过启发式检查，其余未知。可用不代表分割已正确，QA 仍发现阴影和不完整前景。
- 组合：预先固定 RRF .75 SigLIP/.25 另一视觉通道，未经本轮标签调参。缺少的专门通道不产生证据，造成覆盖偏差；因此单通道失败不能解释为“形状没有用”。
- DINO patch：全图 CLS 召回100，再以局部 patch 对应与软轮廓处理通过质量检查的候选；未知候选保留原位置。不是学习式分割，也不能证明具体纹饰语义，独立结果另见 `PATCH_MATCH.md`。

## 全 4,692 图召回的探索性比较

事先固定8类视觉意图：梅瓶、葫芦瓶、青花、青釉陶瓷、青铜礼器、玉牌、红色雕漆、带图案织物。每类参考 ID 先于排名写入 protocol；参考来自图库外。13种方法实际检索全库，各方法前5名取并集得到257条查询–图像判断，涉及244张不同图片，随机编号后只看图判断。主 AI 评四类，另一 AI 评四类；每对查询/图片只有一位 AI 判断，不是真人 gold，也没有双标一致性。

分级0=不相关、1=部分或不可确认、2=可见外观符合。P@5 仅 grade2 为命中；弃权计空结果。相关性的目标是可见外观，不能把青铜、玉、丝的外观当实际材质鉴定。此实验隔离的是**参考图驱动的视觉排序**，不是任意自然语言下的自动参考选择质量。

| 方法 | 平均 P@5 | 可处理查询 | 有效候选图范围 |
|---|---:|---:|---|
| 英文外观描述→图文检索 | .975 | 8/8 | 4,692 |
| 中文描述→图文检索 | .775 | 8/8 | 4,692 |
| 单参考 SigLIP | .625 | 8/8 | 4,692 |
| 多参考 SigLIP 均值 | .675 | 8/8 | 4,692 |
| 多参考 SigLIP 最大值 | .650 | 8/8 | 4,692 |
| 多参考 DINO CLS | .600 | 8/8 | 4,692 |
| SigLIP + DINO | .750 | 8/8 | 4,692 |
| 形状统计单独使用 | .000 | 5/8 | 888 |
| 前景颜色单独使用 | .050 | 5/8 | 888 |
| 前景纹理单独使用 | .000 | 5/8 | 888 |
| SigLIP + 形状 | .700 | 8/8（含弃权退回） | 4,692，专门分支888 |
| SigLIP + 颜色 | .675 | 8/8（含弃权退回） | 同上 |
| SigLIP + 纹理 | .650 | 8/8（含弃权退回） | 同上 |

这些是描述性均值，不是部署胜出证明。仅8个定向选择意图，bootstrap 区间很宽，多重比较未作显著性结论；没有全库穷举相关项，不能报告全库 Recall。Pooled nDCG@5 的理想序列只来自已观察池。完整逐意图结果、区间及标签哈希在 `artifacts/reference_eval/metrics.json`。

具体发现：梅瓶中文直接检索 P@5=0，英文=1，多参考均值=.8、max=1、DINO=1；葫芦多参考均值=.8、max=.2、DINO=1。青花单参考=1、均值=0，混入不同器型/黑白来源图会严重影响原型；青釉均值=.6、SigLIP+DINO=1。玉牌各参考路线均弱。这说明选择合格参考、区分要匹配的属性，比“更多参考图一定更好”更重要。

英文查询有更详细的普通外观描述，中文表达不是严格逐字平行翻译，不能将两行差异独断归因为语言能力。每个候选共用同一份像素 grade，因此 DSH 提到的“中英文使用不同 judge”并不符合本实验。

## DSH 复核与采纳边界

已把上述实现、负结果及用户目标发送给本机 DSH，原始回复在 `dsh_reference_review_response.txt`。有价值的建议是参考按器型/呈色/纹样分组、保留覆盖率及逐意图结果、尝试局部 patch 匹配，并把专业年代与外观分开。局部对应实验已追加，使用独立预声明的弱标签协议，不在8意图盲标池上调权重。

复核中也有必须纠正的事实：颜色描述子已经只用前景，不能将低分直接归因为全图白背景；18.9%覆盖是重要限制但不足以单独解释shape=0；中英文方法共用同一份候选图判断；融合前余弦诊断有明确scope，并非将其冒称最终融合差值。DINO patch14在224输入有16×16 patch；不能混称patch16。DSH建议不作为已验证结论照抄。

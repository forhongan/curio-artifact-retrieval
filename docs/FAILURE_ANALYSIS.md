# 冻结测试失败分析

以下六项由 `failure_shortlist.json` 按 selected image-only 测试的双语最小 nDCG@10 固定选择。分析只依据冻结盲图卡和前五结果，不回改 qrels、模型或参数。

| qid | 观察到的错误 | 可能原因与边界 |
|---|---|---|
| `vt024` | 目标是带凸起盘曲雕纹的长方形雕片；前五主要是白盘、红色装饰片、黑色纹饰牌和浅色碗，只有部分纹饰/片状外观相近。 | 图像空间抓到“装饰片/纹饰”但没有稳定区分长方形、浮雕和盘面；训练中没有足够的专业雕片类别。 |
| `vt014` | 目标高瓶的两侧小耳在第3名出现，另有第4名带耳的青绿色器；前两名是相似高瓶但没有耳。 | 器型和细长轮廓比小把手更显著，细节属性权重在 dev 被选择为0，因此没有用弱监督 handles 头修正。 |
| `vt021` | 目标为圆柱形人物彩绘容器；第1、2、4名是带盖并有人物/动物图案的容器，第5名才是目标。 | 模型优先匹配“容器+人物/盖”，对圆柱形、彩色和具体人物场景的联合约束不足；黑白图和复杂纹饰也增加了外观差异。 |
| `vt006` | 目标带侧柄和外伸流口，第3名才是明确相似的执壶/长嘴器；第1、2名是细长工具，第4名是无关器物。 | 稀有器型和局部柄/流口在224px输入中占比小，模型被长轴和深色轮廓吸引；当前细节头没有通过 dev 提升该查询。 |
| `vt020` | 目标是深色浅盘/托，带建筑山水；第1名是带山水的盘（grade 2），第4名才是目标，其余为盘或碗但纹饰不符。 | 主题纹饰“山水/建筑”召回有效，但颜色、浮雕质感和托盘形状排序不足；颜色与纹饰并非可靠互斥类别。 |
| `vt007` | 目标是蓝白圆形带盖储物罐；第2、5名为带盖彩绘罐，第3名为红色盒，第1名是完全无关工具。 | 盖子部件在当前监督中只支持独立 lid，不代表“容器是否带盖”，且生产选择为零探针权重；密封器物、圆腹和青花联合表述仍容易被装饰物干扰。 |

这些解释是对可见图像和模型行为的工程分析，不是额外标签，也不声称证明单一因果。它们支持后续方向：多裁剪/高分辨率局部特征、增加可见器形与部件监督、以及在 dev 上验证细节重排是否值得部署。test 结果已冻结，本轮不据此调参。

# 从相似度阈值改为查询条件下的视觉二分类

> 此文保留实施前的设计状态。后续已接入模型并完成对照；实际成绩、失败案例与未上线项见 [实现与实测](IMPLEMENTATION_ZH.md)。

2026-11-16。本轮是失败复现、文献核查和替代方法设计，**不是新模型已实现或效果已验证**。v8 的严格规则未满足自由查询、中英文一致和照片颜色可验证的需求，不应作为通用集合边界已经成功的证据。此轮未改变运行中的算法。

## 已证实的问题

重新调用真实 `/api/search/set`，图库 4,692 张：

| 查询对 | 中文 Yes / 待核验 | 英文 Yes / 待核验 |
|---|---:|---:|
| 青花瓷 / blue and white porcelain | 0 / 639 | 33 / 583 |
| 梅瓶 / meiping vase | 0 / 999 | 0 / 1,072 |
| 葫芦瓶 / double gourd vase | 0 / 739 | 0 / 869 |
| 黑色瓷瓶 / black porcelain vase | 2 / 58 | 1 / 63 |
| 白色瓶子 / white vase | 6 / 325 | 6 / 305 |
| 窄口的瓶子 / a narrow-mouthed bottle | 76 / 764 | 76 / 734 |
| 绿色瓶子 / green vase | 10 / 60 | 10 / 58 |

数量不是准确率；同数量也不保证相同集合。详细入选集合交并比在 [双语审计](bilingual_audit.json)，两个空集合不计为成功的一致性。

代码原因：

- `condition_parser.py` 把中文青花映射成 `blue_white_technique/yes`，英文 blue-and-white 映射成 `tag/blue_white`，两种语言实际执行了不同任务。
- 梅瓶、葫芦瓶被主动标为 `specialist_form`，因此没有学习或执行专业器型识别，必然不能产生 Yes。提高相似度或降低阈值不能修好这一点。
- `strict_boundary.py` 对 black/white 跳过了低色度弃权条件。中文“白色瓶子”的 6 个结果中，`met_47334`、`met_48328`、`met_48308`、`met_48637` 这 4 张图所有 RGB 通道相等，不能据此验证器物原始颜色。英文也包含这 4 张。见 [像素审计](color_audit.json)。
- 同义中英文仍进入不同的原句向量与语言分类边界，即使条件词表相同，也可能得到不同候选集。
- 多个不可靠的硬门槛串联，会同时累积漏检。将大量结果放进待核验，并没有完成用户需要的自动二分类。

## 推荐主线

采用 VQAScore 式图文联合判别 + 文物领域正负样本训练 + 独立阈值校准**。保留 SigLIP 用于快速排序、找训练反例和分批调度，取消它作为最终相关/不相关真值的地位。

VQAScore 通过图像与问题共同输入 VQA 模型，计算 Yes 回答的模型分数。论文在通用图文组合匹配基准上报告了相对 CLIPScore 的改进；这支持将它列为本项目的实验候选，**不能外推为中国古代文物的准确率保证**。[原论文](https://arxiv.org/abs/2404.01291)

可先用 Qwen3-VL-8B-Instruct 做看图判别基线，再比较领域适配前后；它不是这里已经验证最优的模型。官方模型提供图像与文本输入；VQAScore 作者代码已提供 Qwen3-VL 适配及 token 评分接口。[官方模型](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct)、[作者实现](https://github.com/linzhiqiu/t2v_metrics)

### 1. 语义归一化，消除语言分叉

把中英文同义表达解析成同一个概念对象，而不是分别拟合语言阈值。例如：

```json
{"concept":"meiping","attributes":[],"negated":false}
```

梅瓶、meiping、meiping vase、plum vase 在确认语义一致时共用概念定义、正负参考图、模型输入、决策阈值和结果缓存。组合查询保留属性归属与否定范围，不能通过删掉未识别词变成更宽的查询。未见过的专业词先检索定义/参考图，不把“词表未覆盖”解释为图库无匹配。

常见专业词应建立经核对的概念库；自由表达用语言模型映射到概念与条件，保留原句用于检查解析是否丢失约束。解析本身也需要双语同义句测试，不能承诺任意语言输入都自动正确。

### 2. 用定义和参考样本识别专业概念

“梅瓶”是可见器型概念，不需要先把它退化为任意窄口瓶。参考小口、短颈、宽肩、下部收束的组合特征，并提供相似但不符合的瓶形反例。博物馆对梅瓶的描述可以提供定义依据。[河南博物院](https://english.chnmus.net/en/collection/details.html?id=418104689879684282)

葫芦瓶的概念参考要覆盖上下鼓腹、束腰及变体，同时用普通圆腹瓶、长颈瓶作为反例。避免仅靠名称向量或一条轮廓比例判定。

“青花瓷”的视觉筛选应采用一致的白地蓝色纹饰外观定义；它不是“蓝色占主体多数”。青花还包含材料与釉下工艺含义，单张照片不能证明化学成分和生产工艺，不能让模型以解释文本伪装技术鉴定。[V&A 青花说明](https://www.vam.ac.uk/articles/chinese-blue-and-white-ceramics)

参考图只提供概念知识；候选藏品标题、目录标签不能成为线上判别的答案来源。同一器物和重复图不得跨训练/参考/测试组泄漏。

### 3. 模型学习近似正例与困难负例的边界

训练单位是 `(图片, 规范查询, 是否满足全部可见要求)`，而不是只有图文配对相似度。联合看图与查询，学习最终二分类；属性与局部裁剪用于辅助证据，不再让一串未校准阈值决定全部结果。

必须加入有针对性的困难负例：宽口但其他部分相似、颜色错误但形状正确、花纹局部同色但主体不同、白底黑纹与白底蓝纹、普通瓶与梅瓶/葫芦瓶、只有瓶盖或残片、画中的瓶子。每个真值按全部查询要求评定，避免总分高补偿某项明确不符。

先比较零样本/参考样本 VQA，再用同一划分训练二分类头或 LoRA；无需预先断言一定需要大规模微调。模型生成的理由或自报“95%置信度”不能当作概率。使用固定问题模板的 Yes/No 分数或专用分类头，并在独立数据上校准。

### 4. 二值输出与颜色可观察性

用户界面可以只输出 Yes（入选）和 No（不入选），不要求用户处理成百上千条待核验。内部仍保留原因：明确不符、证据不足、低支持；不能把未知事实伪装成已经证伪。

建议定义：**Yes = 这张照片提供足够证据满足查询；No = 本次筛选不接受这张照片。**

- 纯黑白图可参与梅瓶、葫芦瓶等形状判断。
- 当查询依赖真实颜色时，无法验证颜色的黑白图应为 No，原因 `color_not_observable`；包括黑色、白色和青花。
- 任何模型都不能从已丢失颜色的灰度照片可靠恢复器物原色；这不是换模型可以保证解决的问题。
- 查询或模型执行失败应报错误，不能伪造一次正常的全库 No 结果。

最终决策可写为 `Yes = visible_requirements_observable AND calibrated_joint_score >= threshold`。这是一套预测规则，不是对任意查询永远正确的数学分割。

### 5. 校准边界，不能靠样例调阈值

在开发集选择模型，在独立校准集选择阈值，最后在未用于调参的测试集报告 Precision、Recall、误收率、空结果率、双语集合一致性和耗时。阈值按概念/任务适配且需足够样本；同一个概念中英文共用。证据不足时不能宣称该阈值达到某个准确率。

建议把高精确率与最低召回要求同时设为验收条件，避免“全 No”通过测试。目标数值应作为待验证的需求，不能作为已有成绩。对样本足够且分布假设合理的场景，可进一步用 Learn then Test 做风险控制；其保证依赖抽样与校准条件，不覆盖任意新专业名词或分布漂移。[Learn then Test](https://arxiv.org/abs/2110.01052)

## 全库要求与成本

4,692 张图可以做整库分批判别，但联合视觉模型比一次向量点积昂贵。新概念首次批量计算并缓存结果；同义词复用。常见概念可离线建索引，待有可靠训练集后蒸馏轻量视觉分类头。

如果为了速度先取固定 Top-K，必须测候选召回，并承认池外图未验证；不能把 Top-K 结果宣称为完整 Yes 集合。首轮实验先测每图耗时、内存和全库成本，随后决定全量扫描还是经验证的预筛。

## 下一轮实验验收

固定当前 v7/v8 为历史对照，先做以下三个实验，不直接把未验证模型替换默认：

1. 原始相似度 + 校准边界。
2. 统一概念输入 + VQA 二分类。
3. 同一 VQA 模型 + 正负参考/领域困难负例适配 + 校准。

首批覆盖青花瓷、梅瓶、葫芦瓶，以及瓶/罐/碗、长颈/窄口、颜色、纹样和组合查询。必须包含用户未举例的新概念。分别使用真实灰度图片、颜色可见照片、近似反例、随机图库背景和独立器物正例。人工核查作为最终真值；AI 预标签只做辅助。

按器物组划分数据，隔离重复图片；再做概念留出检验迁移。翻译同一个查询不会增加独立测试意图数量。困难负例集合不能直接估计全库 Precision，还需具有图库代表性的抽样或适当加权。

当前项目有 SigLIP 缓存及部分大类属性探针，但未接入上述联合判别模型。现有探针不包含梅瓶/葫芦瓶，color 为 insufficient_support；不能简单切换一个现成探针就宣称问题解决。本轮没有下载新模型、调用付费推理或训练模型，也没有生成新的准确率成绩。

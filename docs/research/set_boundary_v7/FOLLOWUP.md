## 图像检查观察

已查看 5 张摘要页，以下为 AI 辅助观察，不回写原标注：

- **部件漏检。** `met_48483` 的壶照片清楚可见柄与长流，却在倾倒器/带柄条件下被拒；`cma_136630` 的杯也有明显把手。这提示全局分数对局部部件不够稳定，值得下一轮测试局部视觉证据。
- **整体与部件混淆。** “带盖罐”漏掉摘要页中 4 张明显带盖的罐；误收的 `cma_101736` 是独立塞子，馆藏记录标题为 “Snuff Bottle (stopper)”。下一轮困难负例应包含“有盖的完整器物”与“独立盖/塞子”。标题仅用于失败审阅，没有用于检索评分。
- **器物附属结构可能有歧义。** `cma_134997` 馆藏标题为 “Five-Spouted Vase with Cover”，不能把所有突起都当柄。需要把流、耳、柄分别标清，避免一个“handles”概念承担多个部件。
- **花卉类别混淆。** 荷花查询收进多种一般花卉装饰；例如 `met_47859` 记录只说明 flowers，单凭整图不能可靠确认具体植物。对于细小、刻划或高度抽象纹饰，应保留未知，并由第二位标注者复核。不可把官方记录未写 lotus 自动当作“图中没有莲花”。
- **材料近似误收。** 织物查询的 3 个错误候选在摘要中表现为书写载体、环状器和雕刻件，需要补充“装饰/平面外观相近但主体材质不同”的负例。

以上解释是下一轮假设，不是已证明的因果归因。

## 标注与后续实验顺序

1. 人工逐图核对查询中的全部必要条件。填 3=全部满足，1=部分满足且有明确不符合条件，0=不相关，-1=证据不足。标签不能由模型预测或仅凭标题代填。
2. 颜色在黑白照片中不确定、纹样太小、材料无法辨认时记录证据不足；让第二位标注者复核分歧，并写 notes。
3. Test 标签冻结后不参与提示词选择、特征设计或阈值选择。只在新 dev 上选择预先声明的方法，再一次性计分新 test。
4. 优先比较：当前默认、中文原句＋英文条件描述、部件局部证据；所有设置应在看到新 test 结果前固定。新方法须写新版本协议。

目前 720 条标签均为空，因此尚不能报告新测试成绩。抽样可能导致某些意图正例很少或为零，要如实报告；不能看到模型结果后补选“容易的正例”。这仍是样本评测，完整图库召回率需要针对若干固定查询穷尽审阅图库。

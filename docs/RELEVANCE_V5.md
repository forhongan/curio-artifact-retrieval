# 评测核心 v5.1

这套评测把实际查询需要的条件作为相关性定义，降低“单一标签不一致就判错”和“只满足大类也判对”两种偏差。标签用于产生可审计的判断，不是线上候选检索依据。旧评测原文件保留，不能把不同协议的分数直接相减。

## 样本和核查

`eval/relevance_v5/` 包含 200 张图：60 dev、140 test。120 张来自历史视觉评测，新增 80 张从 test 按材质轮转、对象组去重、固定哈希抽样。主代理实际打开全部 20 张联系表，逐件阅读完整缓存馆藏字段，记录 `visual_review.tsv` 的器型、多个可见特征及说明。联系表图片最大约 340 像素；未宣称每张原图都作了专家级细查。

200 条图像／来源核查，经明确条件规则展开成 20 个语义意图与 4,000 个查询图像判断。中英文是同一意图的两种输入。它们不是 4,000 次独立人工标注，也不是新盲测的人工金标准；历史测试图曾被观察，新增样本也不是全库的等概率样本。

## 相关性

- `relevant / 3`：所有必要条件满足。瓶／花瓶、碗／水盂、盘／碟／浅盆等在相应宽查询中兼容，精细器型仍保留。
- `partial / 1`：部分条件满足，但有明确矛盾。二值集合中算不符合；nDCG 中保留部分相关收益。
- `irrelevant / 0`：没有满足的必要条件且有明确矛盾。
- `unknown / -1`：没有已知矛盾，但证据不足。不能作为错例，也不能作为正确例。

颜色考虑黑白照片不可判色；人物、动物、花纹可以多标签并存。花卉类包含程式化植物卷草；莲花形状本身不等同于表面莲纹。主材质区别于附件材质。专业年代条件来自官方记录，不能由外观相似替代；仅“清代”不能证实或排除“乾隆”，仅“金属”不能判定“不是青铜”。存在明确其他时期或不相交日期时才可判负。

原评审冻结在新检查点排名产生之前。v5.1 在检查评分代码时修正粗年代／粗材质的未知传播，以及空视觉条件被判为全满足的问题；没有针对新模型的失败图片重写可见标签。初版快照保留在 `history/evaluation_v5_initial/`，哈希与现行协议在 `freeze.json`。`visual_only_status` 只是衍生诊断，专业意图删除事实条件后为空时为 unknown，不能当作另一个准确率。

## 指标与范围

排序报告 known-only P@5 和 nDCG@10，并附判断覆盖率。未知项从排序指标移除，因此不能把 known-only P@5 当作未经删选的实际前五准确率。另有完整返回样本的逐项读图审计。

集合对每条查询计 TP、FP、FN、接受未知数，报告宏／微 Precision、Recall、F1；宏 Precision 同时给出有定义的查询数和空集合数。未知接受项计入精度上下界：下界 TP/全部接受，上界 (TP+未知)/全部接受。

每种方法对全 4,692 图片评分和作边界决策，但检索质量的穷举真值只覆盖 140 张 test 核心，集合召回不能外推为全库召回。开发集边界在相同意图的 60 张不同对象上拟合，尚未证明对未见查询的泛化。20 个语义意图的配对 bootstrap 将中英文先平均，不能虚增为 40 个独立样本。

## 重跑

```powershell
.venv/Scripts/python.exe scripts/freeze_relevance_v5.py
.venv/Scripts/python.exe scripts/evaluate_relevance_v5.py
.venv/Scripts/python.exe scripts/evaluate_teammate_workflow_v5.py
.venv/Scripts/python.exe scripts/evaluate_image_components_v5.py
.venv/Scripts/python.exe scripts/summarize_relevance_v5.py
```

不变检查点直接复用图库向量。下载的新适配器实际加载后，只重编码 16 张样本核对其已发布索引，余弦最低约 .999997；文本塔也实测未变。完整编码耗时沿用既有独立性能实验，不在每次质量测试中重算。

结果入口：`artifacts/relevance_v5/results.json`、`RESULTS.md`、`paired_bootstrap.json`。更多样本会增加评测成本，当前先用这套可复查核心比较算法，不继续扩大非必要标签研究。

## 从原文件保留的要求

课程原文要求领域定义、合法图库、自建查询及相关图像标签、算法比较、可使用的系统、至少一种检索质量指标、失败分析及 AI 使用披露。11 月 18 日展示和 11 月 25 日报告是后续交付时间。原规划可用的技术思路是双塔表示、领域微调、混合检索、可解释查询约束、统一评测，以及可开关的对照实验。

## 实施顺序

1. 实测数据接口与许可，下载中国古代器物原图和原始元数据；目标 5,000 件，优先清晰的单器物，记录不合格与失败原因。
2. 固定主表、唯一 ID、图像哈希、来源、许可、尺寸、去重和 train/dev/test 对象分组。保留长宽比；显示缩略图与模型原生预处理分离。
3. 跑通 CLIP 基线和 SigLIP2 紧凑模型；比较英文与中文查询通道，记录真实本机速度。
4. 构造面向可见性、但由馆藏字段生成的弱监督训练 caption，显式移除年代、朝代、馆名等字段后进行图像塔 LoRA 训练。标题、器名、材质和纹饰仍可能携带艺术史身份或用途语义，不能称为人工视觉描述；按未参与训练的对象验证，不得将同一件文物不同视图拆入训练与测试。
5. 实现中英解析、BM25、稠密检索、RRF 融合、明确用户筛选及证据面板；训练改进只有在验证收益成立时成为默认配置。
6. 建立两类独立评估：留出图文配对检索和自由查询相关性评估。机器生成/元数据派生标签明确标为 silver，不冒充人工双标；提供真正人工标注工具和导入接口。
7. 集成前端、API、模型和实际图库；运行指标测试、API/过滤/否定/路径安全测试、训练保存重载检查、端到端浏览器与延迟测试。
8. 冻结数据和配置，产出可复现实验表、失败样例、运行命令、依赖锁及已知限制。

## 验收证据

- 实际存在且可解码的本地图像，图像与许可台账一一对应；下载脚本可断点续传。
- 中英文查询能返回真实图像，baseline/hybrid 可对比，来源与字段证据可追溯。
- 至少两个预训练模型对比、一次实际领域训练及与零样本对照，包含负结果和选择依据。
- nDCG@10、P@5、AP@10、Recall@20、MRR 的实现有手算/独立库验证；对象留出配对检索单独报告 Recall@K。
- 结果表记录模型/数据哈希、随机种子、评测标签来源和实际耗时；不把 silver 指标说成人工金标准。
- README 可从当前仓库重建索引、启动应用、复现实验与测试。

## 决策与限制

- RTX 3070 8GB，32GB 内存：先使用 CLIP B/32 与 SigLIP2 base，不预先承诺 7B VLM 的实时并发核验。是否引入小型视觉核验器由实测决定。
- 5k 规模先用归一化 NumPy 精确内积，无需为 ANN 引入额外平台；保留替换接口。
- 训练 caption 严格排除年代/朝代，馆藏文字描述单列保存；剩余标题、器名、材质和纹饰仍是元数据弱监督，不能称为人工视觉识别。
- 相同标题/模板的样本不是可靠负例；训练需处理重复 caption 的多正例或去重 batch。
- 不自动放宽用户显式 facet。数量和空间查询如未验证，只标未核验，不能编造视觉理由。
- 数据源评估中提到的样本目录当前不存在；其数量、端点和许可必须重新实测。
- `talk_with_dsh.txt` 当前为 0 字节，暂没有可用的 DeepSeek harness 通信方法。

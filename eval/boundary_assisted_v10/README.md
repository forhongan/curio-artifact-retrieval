# AI 与馆藏资料辅助复核 v10

用户明确授权由助手结合图片和图片附带标签完成复核。本批已实际查看 120 张图片对应的 6 张联系表，并放大核查织物纹样；依据逐图写入 `visual_facts.jsonl`，再按 12 条查询生成 720 个判断。未调用当前 Qwen/SigLIP 检索模型给自身生成答案。

## 完成结果

- 8 项满足要求；690 项有明确不符条件。
- 14 项照片颜色不可观察，按严格筛选不入选，无需人工补色。
- 8 项存在碗/杯、瓶/罐、莲瓣器形/花纹等语义边界，按严格筛选暂不入选，保留可选复核入口。
- 所有 720 项都有布尔 `decision`：8 Yes、712 No。`grade` 仍区分明确负例 0、正例 3、证据不足 -1，避免把实物未知事实冒充已证伪。

原队列为随机图库背景抽样，正例仅 8 项；红色碗、玻璃瓶、青铜动物等意图没有确认正例。这一批不能单独用来训练或宣称覆盖这些概念的召回率。后续应补充正例与相似反例，而不是扩大明显负例的重复复核量。

## 来源与使用范围

- 器形、可见颜色与纹样：root AI 对实际图片的判断。
- 材质：保留原始馆藏 `medium` 值与来源链接，标明 `catalogue_medium`，不称为像素可证明的化学材质。
- 馆藏红釉、蓝釉等文字不用于恢复灰度照片颜色。
- 所有记录均为 `human_confirmed=false`、`independent_human_gold=false`，是辅助标签，不是独立人工金标准。
- 保留原 dev/test 与器物组划分；test 标签不能用于拟合或校准。当前未进行新训练、未报告准确率提升、未修改检索算法。
- 原始冻结 `independent_labels_pending.csv`、盲复核 bundle 与浏览器里已有人工记录均未覆盖。

## 文件及复现

`visual_facts.jsonl`：120 条已看图事实和说明。

`labels.jsonl`：720 个图文判断、逐条件依据、原查询、原分组及来源。

`manifest.json`：统计、来源哈希和使用限制。

`review_queue.json`：原始 720 项冻结队列，供后端独立复核与测试，无需前端资产目录。

```bash
PYTHONPATH=src .venv/bin/python scripts/export_assisted_review.py
# 如前端需要复核页面数据，可显式添加 --web-output <目标 JSON 路径>。
```

页面 `http://127.0.0.1:8000/#boundary-review` 默认显示 8 项歧义，支持查看全部、正例、明确负例与颜色排除项。AI 导出与人工导出分开；人工更正单独保存在浏览器，不改写辅助标签。

验收：新增 5 项语义/来源测试通过，全量 583 passed / 13 skipped；Ruff、前端构建通过。浏览器检查默认 8 项、分类筛选、720 项导出、人工记录保留、移动布局和无页面错误。浏览器合成测试记录已清除，不进入数据集。
